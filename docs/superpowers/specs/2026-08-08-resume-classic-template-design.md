# 简历经典版式模板与 AI 基类内容更新 · 设计

日期：2026-08-08 · 状态：待评审

## 1. 背景与目标

现状：简历生成走"facts.yml → 通用 HTML 模板 → 无头 Chrome 转 PDF"，版式与用户原始简历（`profile/王奕迅_AI应用.pdf`，LaTeX resume 模板排版）不一致；且用户希望 AI 应用岗简历中博世 AI 实习内容更丰富、与岗位更贴合。

目标：
1. 生成简历保持原始简历的排版格式（姓名+联系方式置顶、教育/实习/项目/技能/荣誉五节、公司行"公司·地点｜时间"、岗位行"角色｜技术栈"、要点加粗关键词、A4 单页优先）。
2. 内容按 JD 方向在 AI/ADAS 两份基类间选择，AI 基类使用已确认的新内容（博世段扩写、霍莱沃段按"电磁与信号感知部门·仿真数据处理与工具开发"口径改写）。
3. 保留现有能力：PDF 预览、页数显示、意见反馈重新生成、LLM 润色、QA 校验。

## 2. 关键决策

### 2.1 渲染方式：HTML 复刻，不走 LaTeX 编译

实测：本机 MiKTeX 未完成初始化（fresh installation），`resume.cls` 不在系统中，原 PDF 系在别处编译。自动管线依赖 LaTeX 编译不可靠。采用 HTML/CSS 复刻原版式，`.tex` 文件仅作版式参照。

### 2.2 删除自选板块

原简历没有"核心优势""岗位匹配亮点"两个板块，为忠实还原版式，新模板删除这两个板块。JD 针对性由 LLM 润色内容保证。

### 2.3 分节标题无图标

原版式标题带 FontAwesome 图标（🎓👥💻⚙️🏆）。HTML 离线生成引入图标字体不稳，改为纯文字标题 + 标题下细横线。

## 3. 版式规格（`lib/resume-classic.mjs` 新增）

输出结构（自上而下）：

1. 姓名（居中，约 16pt）+ 联系方式一行（电话 · 邮箱，居中）。
2. 五节：教育背景 / 实习经历 / 项目经历 / 技术技能 / 荣誉与奖项。
3. 公司行：`公司 · 地点` 左对齐、时间右对齐（还原 `\datedsubsection` 的 `\hfill`）。
4. 岗位行：`角色 ｜ 部门` 左对齐、技术栈右对齐灰色小字（还原 `\role`）。
5. 要点：圆点列表，JD 关键词 `<strong>` 高亮。
6. 荣誉行：`标题 ｜ 内容` 左对齐、年份右对齐（还原 `\datedline`）。

CSS 要点：
- A4（210mm），页边距约 13-15mm；西文 Times New Roman、中文宋体（SimSun）；
- 正文字号约 9.5-10.5pt、行距 1.3 左右，以单页为目标；正文过长由 QA 警告提示；
- 分节标题加粗，标题下方 1px 细横线。
